# n8n Workflows

The repository contains sanitized n8n workflow exports for the AI Healthcare Analytics Assistant.

Before importing into another n8n instance, reconnect the required credentials for Gemini, Snowflake, and Google Sheets and set the Google Sheets document ID used for backend audit logging. The main workflow references the Healthcare SQL Tool as a sub-workflow.

No API keys, passwords, private keys, or live credential objects are included in these public exports.
